# Proposals

Substantial changes to the Asset Notation data model are recorded here as short design
notes, so the *why* survives next to the *what*. Small or editorial fixes do not need a
proposal - open a pull request directly.

## Process

1. Open a *Change proposal* issue describing the problem (see
   [CONTRIBUTING.md](../CONTRIBUTING.md)).
2. Add a note in this folder named `NNNN-short-title.md` (zero-padded sequence number),
   based on the template below.
3. Iterate in the pull request. When accepted, the note's status becomes `accepted` and
   the change lands in a new specification version.

## Status lifecycle

`draft` -> `accepted` -> `implemented` (or `rejected` / `withdrawn`, with a reason).

## Template

```markdown
# NNNN - Title

- Status: draft
- Author: <name>
- Created: YYYY-MM-DD
- Target version: 0.x.0

## Problem

## Proposal

## Compatibility

## Alternatives considered
```
